# JN Delniški portfelj

Osebna aplikacija za spremljanje delniškega portfelja: pregled pozicij in donosov, uvoz iz IBKR,
N26 in nakupnih listov ter priprava davčnih napovedi Doh-KDVP in Doh-Div.

- Specifikacija: [docs/SPEC.md](docs/SPEC.md)
- Nastavitev: [docs/NASTAVITEV.md](docs/NASTAVITEV.md)

Repozitorij vsebuje samo kodo. Finančni podatki so v zasebni bazi in niso nikoli shranjeni tukaj.
